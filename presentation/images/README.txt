Sweet1ne - images for index.html
=================================

Drop your custom images here. The presentation tries each filename first,
then falls back to an Unsplash photo if the file is missing.

Walkthrough slide images
------------------------
  landing.png      Slide 1 - landing / hero image
  qrcode.png       Slide 2 - QR code at the table
  kitchen.png      Slide 6 - kitchen / service scene (above dashboard mock)
  dashboard.png    Slide 7 - admin dashboard screenshot (centre image)

Recommended: landscape 4:3 or 16:10, ~900-1200px wide, good lighting.

Dish photos are loaded from Unsplash in-page (no local files needed).
