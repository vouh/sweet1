# Sweet1ne Visual Menu Pilot Proposal

Prepared for: Sweet1ne  
Prepared by: GlobalSolutions  
Project: Mobile-first restaurant visual menu  
Date: June 2026  

---

## Executive Summary

GlobalSolutions proposes building Sweet1ne a mobile-first visual menu platform for its London branches.

Customers will scan a QR code at the table and instantly open a web-based menu without downloading an app. The menu will show real dish photos, prices, descriptions, dietary and allergen information, popular items, and search.

Sweet1ne will also receive a secure admin dashboard to manage menu content, update dishes, change prices, upload photos, and mark items available or unavailable.

The first version will focus on a controlled pilot in one branch before expanding to the second branch. This keeps the project practical, measurable, and easy to improve based on real customer usage.

---

## The Opportunity

Restaurant customers often make faster and more confident choices when they can see the food clearly. A visual menu gives Sweet1ne a stronger way to present dishes, especially signature items, popular dishes, and higher-value meals.

This project is not just a replacement for a paper menu. It is a visual sales and insight tool.

The platform will help Sweet1ne:

- Improve the customer menu experience.
- Present dishes with stronger visual appeal.
- Reduce friction for customers browsing at the table.
- Update menu content without reprinting menus.
- Understand which dishes customers view and search for.
- Test whether visual presentation improves sales of selected dishes.

---

## What Will Be Built

### Customer Menu

Customers will scan a QR code and open a mobile-friendly web menu.

The customer menu will include:

- Branch-specific menu access.
- Menu categories.
- Dish listing pages.
- Dish detail pages.
- Real dish photos.
- Prices.
- Descriptions.
- Dietary and allergen tags.
- Popular dish badges.
- Search.
- Availability status.

### Restaurant Admin Dashboard

Sweet1ne staff will have secure access to a simple dashboard.

The dashboard will allow staff to:

- Add, edit, and remove dishes.
- Add, edit, and remove categories.
- Upload or change dish photos.
- Update prices.
- Mark dishes as available or unavailable.
- Manage branch-specific menu content.
- View basic analytics.

### Analytics

The platform will capture useful menu engagement data, including:

- QR scans.
- Dish views.
- Category views.
- Search terms.
- Branch-level usage.

This will help Sweet1ne understand which dishes attract the most attention and how customers interact with the menu.

---

## Pilot Strategy

GlobalSolutions recommends launching the first version as a pilot in one branch.

The second branch can continue operating normally during the same period. This gives Sweet1ne a practical comparison between the pilot branch and the non-pilot branch.

The pilot should focus on 10-15 starter dishes first. These dishes should have strong photos, accurate descriptions, confirmed prices, and baseline sales figures before launch.

This approach allows Sweet1ne to measure whether visual presentation increases attention and sales for selected dishes.

---

## Delivery Plan

### Phase 1 - Setup and Content

Confirm the first pilot branch, starter dishes, photography, menu structure, pricing, descriptions, dietary information, allergens, and baseline sales figures.

Outcome:

- First branch confirmed.
- 10-15 starter dishes selected.
- Dish content prepared.
- Sales baseline captured.
- Menu structure agreed.

### Phase 2 - Platform Build

Build the customer menu, QR flow, admin dashboard, photo management, availability controls, and analytics.

Outcome:

- Customer menu working.
- Admin dashboard working.
- QR codes generated.
- Analytics captured.

### Phase 3 - Internal Testing

Test across mobile phones, browsers, slow network conditions, QR code scans, admin workflows, and branch-specific menu data.

Outcome:

- Product tested before public launch.
- Critical issues fixed before pilot.

### Phase 4 - Live Pilot

Launch the visual menu in one branch and monitor usage closely.

Outcome:

- Customers begin using the QR menu.
- Sweet1ne receives early usage data.
- Feedback is collected from staff and management.

### Phase 5 - Review and Expansion

Review analytics, customer usage, selected dish sales, and staff feedback. If the pilot performs well, expand to the second branch.

Outcome:

- Pilot results reviewed.
- Improvements identified.
- Second branch rollout decision made.

## Proposed Timeline

Once the first branch and starter content are confirmed, GlobalSolutions expects to reach a live pilot in approximately 6 to 8 weeks.

Recommended timeline:

- Setup and content preparation: 1 week.
- Core build: 3 to 4 weeks.
- Internal testing and fixes: 1 week.
- Live pilot: 2 to 4 weeks.
- Review and second-branch planning: 1 week.

The pilot period should run for at least 2 weeks, with 4 weeks preferred for stronger results.

---

## Scope for Version 1

Version 1 should stay focused on the visual menu, admin dashboard, branch-specific content, and analytics.

Included in v1:

- QR-based mobile web menu.
- Branch-specific menus.
- Dish photos, prices, descriptions, dietary tags, and allergen tags.
- Popular dish badges.
- Search.
- Secure admin dashboard.
- Dish/category management.
- Photo uploads.
- Availability controls.
- Basic analytics.

Not included in v1:

- Online ordering.
- Payments.
- AR.
- AI recommendations.
- Loyalty system.
- POS integration.
- Delivery app integration.

These can be considered as future improvements after the pilot proves value.

---

## Success Measures

The pilot will be considered successful if:

- Customers scan and use the menu consistently.
- Dish pages receive meaningful views.
- Sweet1ne staff can update menu content easily.
- The analytics reveal useful customer interest patterns.
- Selected dishes show stronger attention or sales movement.
- Sweet1ne sees enough value to expand to the second branch.
